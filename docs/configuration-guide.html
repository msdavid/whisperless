Every knob, explained in plain English

Whisperless turns your voice into typed text. All of its settings live in one file — ~/.config/whisperless/config.conf — and this guide explains what each one does, when you might want to touch it, and what changing it costs you. No systems knowledge required: if a word like "KV cache" shows up, it comes with a translation.

§Start here

The one-minute mental model. Whisperless has two parts: a listener (the app you trigger with your hotkey) and an AI brain (a speech recognition engine that runs on your computer's graphics card). The settings in this guide mostly fall into two buckets — things about you and your keyboard, and things about the AI brain.

How changes take effect: settings marked next dictation apply the moment you start your next recording — just edit and go. Settings marked re-run installer are copied into the AI brain's startup configuration when the installer runs, so after editing you must re-run ./install.sh once (it copies the new values and restarts the brain for you). For that reason, restarting the brain on its own — for example with systemctl --user restart whisperless — is not enough: it would come back with the old values still copied in.

§How to change a setting

~/.config/whisperless/config.conf

Open that file in any text editor. Every setting is one line that looks like KEY=value, and the lines starting with # are explanations you can ignore or rewrite. Edit a value, save the file, and apply it as described above. If you ever break the file, deleting it and re-running ./install.sh rebuilds it with factory defaults.

§Everyday settings

The handful you're most likely to ever touch.

HOTKEY default CTRL + space re-run installer

The key combination you press to start recording, and press again to stop and get your text. Use any combination your keyboard has, written like SUPER + K (SUPER is the Windows/⌘ key) or CTRL + space.

When to change: if the current combo collides with a shortcut you use in other apps (for example, CTRL+space starts autocomplete in some code editors). After changing, the installer moves the binding for you.

MAX_SECS default 120 next dictation

A safety stop: if a recording somehow keeps going, it is finalized after this many seconds and your text appears anyway. It exists so a forgotten recording can't run forever.

When to change: only if you regularly dictate longer monologues than two minutes. Raise it to, say, 300. Lower it if you want a forcing function for shorter thoughts.

§Accuracy & word choice

Settings that change what the AI writes down. These are the highest-value knobs for everyday use.

CONTEXT default (empty) next dictation

A cheat-sheet you hand to the AI before it listens: names, product names, jargon, or the topic you're about to discuss. Speech models are surprisingly good at English in general but regularly mangle words that aren't in their vocabulary — company names, people's names, acronyms. This setting tells the model what to expect, and it will favor those words when the audio is ambiguous.

Write anything helpful, up to a few paragraphs. Real example: if you keep getting "Raffinate" when you say Refinitiv, set CONTEXT=Refinitiv, FST, Celerris, Hamish.

When to change: whenever you notice the same wrong word appearing repeatedly, or before a call/project full of specialized terms. Empty is perfectly fine for casual chat.

CONTEXT=Refinitiv, FST, Celerris, Hamish

VOICE_LANG default English next dictation

Which language you'll be speaking. You can name one language, or use zhen for automatic Chinese-and-English mixing (handy if you switch mid-sentence).

When to change: when you dictate in a different language, or mix Chinese and English. Telling the model the language removes its need to guess — usually more accurate, occasionally worse if you actually switch languages.

SMOOTH default off next dictation

A one-word instruction to the AI: "smooth the text" — tidy it up, polish phrasing. Useful if you speak in fragments and want cleaner sentences out.

When to change: try SMOOTH=1 if you want dictation that reads like prose. Turn it off if you need a faithful, word-for-word transcript.

USE_VAD default off next dictation

Turns on a pause detector. While you dictate, it notices when you stop talking for a moment and commits the words so far as a finished sentence — like the pause between paragraphs being turned into a period. Everything still appears in order; the text just gets "banked" in chunks instead of one blob at the end.

When to change: try it if you dictate long stretches and want the on-screen text to feel more settled. Leave it off if you pause a lot mid-sentence (a pause would then cut your sentence in the live view — your final text is still re-checked at the end, but the live text may look jumpy).

ROLLBACK_PUNCTUATION default off re-run installer

Behind the scenes, the AI keeps the last few words "in pencil" and can still rewrite them as it hears more. This setting says: once a sentence ends with punctuation, stop rewriting the words before it — lock them in pen.

When to change: experiment. It can make the live text steadier and reduce endless small revisions, at a small risk of locking in a mistake the model would otherwise have fixed. re-run installer to apply.

§Typing & timing

Your finished text has to be "typed" into whatever app you're using, by pressing virtual keys. These settings control that last step.

TYPER default auto next dictation

Which helper program actually presses the virtual keys: wtype, ydotool, or xdotool. They do the same job on different desktop systems; auto picks the right one for yours and falls back to the next if one fails.

When to change: almost never. Pin one only if you have a specific reason — for example, a program that ignores one helper's keypresses but accepts another's.

SETTLE_DELAY default 0.15 seconds next dictation

A short breath before the virtual keys are pressed. Your hotkey includes a modifier key (like CTRL), and the computer needs a blink of an eye to register that you let go — otherwise the typed text could arrive while the system still thinks CTRL is held, triggering other shortcuts.

When to change: only if you see stray behavior right when text appears (wrong menus opening, characters swallowed). Try 0.3. Lower values make text appear marginally sooner.

GRACE_TAIL default 0.25 seconds next dictation

After you press stop, the microphone keeps listening for this long and adds what it hears. Your mouth is often still finishing the last word as your finger hits the key — this catches it.

When to change: if the last word of every dictation gets cut off, raise it (0.4). If you sometimes get a stray breath or "mm" appended, lower it (0.1).

TRAILING_SPACE default on next dictation

Types one space after your text, so when you continue by hand the next word doesn't glue itself to the last dictated word.

When to change: set TRAILING_SPACE=0 if you find the extra space annoying, for example when dictating into fields that trim poorly or when ending sentences exactly.

§Microphone & media

MIC_TARGET default (system default microphone) next dictation

Which microphone to record from. Empty means "whatever the computer currently considers its default microphone" — usually exactly what you want, and it follows you when you plug in a headset.

When to change: if recordings pick up the wrong device (e.g. you want the laptop mic while a conference app grabs the headset). Find the number to put here by running wpctl status in a terminal — each source has an id, e.g. MIC_TARGET=60.

PAUSE_MEDIA default on next dictation

While you dictate, any music or podcast that is currently playing politely pauses, and resumes when you're done. Only players you had already paused yourself stay paused. Works with Spotify, browsers, video players — anything that follows the standard media controls.

When to change: set PAUSE_MEDIA=0 if you'd rather background music just keep playing, or if the pause/resume behavior annoys you.

§Looks & feedback

NOTIFY default on next dictation

Small desktop popups: "recording started", and a preview of the finished text. Your quiet confirmation that things worked.

When to change: NOTIFY=0 for total silence.

BORDER default on re-run installer

While recording, the outline of your active window turns red, so you can see at a glance whether you're being recorded — even on a different monitor. When you finish, your original outline colors are restored exactly.

When to change: BORDER=0 if you find the red border distracting.

BORDER_COLOR and BORDER_INACTIVE_COLOR red variants re-run installer

The recording color itself, for the window you're typing into and for the other windows. The format is rgba(rrggbb aa) — six digits for the color (like web colors), two extra digits at the end for transparency (00 invisible, ff solid).

When to change: pure taste. Example: a calmer amber — BORDER_COLOR="rgba(ffaa33ff)".

WM default auto re-run installer

Which desktop system you use, so the installer writes the hotkey binding in the right place. auto detects it.

When to change: only if detection ever picks wrong on an unusual setup.

§AI engine tuning

These control the AI brain that runs on your graphics card. Picture the brain as an office worker: GPU memory is desk space, and the KV cache — the term you'll see below — is the worker's notepad: short notes about everything heard so far, so it doesn't have to re-read the whole conversation for every new word. Bigger notepad = remembers more = more desk space needed. All of these are safe to leave at defaults; they're here so the brain can be squeezed onto a graphics card that's also running your desktop, games, or other AI work. re-run installer applies to every setting in this section.

GPU_MEM_UTIL default 0.55 re-run installer

The fraction of your graphics card's memory the AI brain claims when it starts — here, 55%. The rest stays free for your desktop, browser, and games. This is the single most important number for keeping the machine pleasant to use while dictation is available.

When to change: raise it (e.g. 0.7) if dictation is the heavy workload and you want more headroom for long dictations; lower it if your desktop or games are starved. Too low and the brain refuses to start (it literally won't fit).

MAX_MODEL_LEN default 8192 re-run installer

The size of the notepad: how much "recent memory" the AI may keep at once, counted in word pieces (tokens). A token is roughly a syllable-to-word of speech. 8192 tokens needs about 1 GB of memory with this model — that's the sweet spot on a 16 GB card shared with a desktop.

When to change: raise it for very long dictations with the extra memory to spare; lower it (e.g. 4096) to save roughly half a GB. Halving this number is the most effective way to free graphics memory.

MAX_NUM_SEQS default 8 re-run installer

How many recordings the brain will handle at the same time. Eight is generous for one person (you can literally only speak into one microphone at a time); the factory default of hundreds is for server farms. Setting it low reserves memory for the notepad instead of for imaginary second and third speakers.

When to change: leave it. Only raise it if several people on your network dictate at once — and note the default BIND_IP doesn't allow that anyway.

KV_CACHE_DTYPE default auto re-run installer

The precision of the notepad's handwriting. auto means full detail. fp8 means "write in shorthand" — the notes take half the space, leaving room for a longer memory, with a tiny chance of slightly less accurate text on difficult audio.

When to change: try fp8 when you want a bigger MAX_MODEL_LEN but can't afford the memory at full detail.

MAX_NUM_BATCHED_TOKENS default 2048 re-run installer

How much work the brain bundles into a single micro-second of computation. Small values make the running text update smoothly (nothing big blocks the pipeline); large values favor bulk efficiency. For one person dictating, small is right — 2048 is the tuned value.

When to change: don't, unless you're benchmarking. It interacts with MAX_MODEL_LEN in ways that can prevent startup.

MAX_NEW_TOKENS default 1024 re-run installer

When you press stop, the brain re-listens to the entire recording once more and writes the final, best version of your text. This is the word budget for that final pass. 1024 tokens comfortably covers several minutes of speech.

When to change: raise it only if you dictate very long stretches and notice the final text coming out shorter than what you said. Costs nothing at rest.

TEMPERATURE default 0.0 re-run installer

The AI's risk appetite when choosing words. 0 means "always pick the most likely word" — exactly what you want from a transcriptionist. Higher values make it creative, which is wonderful for writing poetry and terrible for dictation.

When to change: don't. This exists so you can, not because you should.

REPETITION_PENALTY default 1.0 re-run installer

A leash against one known AI failure mode: getting stuck in a loop and repeating the same phrase over and over. Values above 1.0 (try 1.1) make repeats less likely. 1.0 means the leash is slack.

When to change: if you ever see the same phrase loop in the final text, set 1.1. If proper nouns start coming out subtly wrong, go back to 1.0 — the leash can also suppress legitimately repeated words.

CHUNK_SIZE_MS default 160 re-run installer

How often the brain looks at the microphone: every 160 milliseconds it processes the latest slice and updates the live text. Smaller = snappier live text but more work for the graphics card (it re-reads its whole notepad each time). Values from 80 to 2000 are supported.

When to change: 320 halves the workload if the GPU is busy with something else; the live text just updates in bigger steps. Your final text quality doesn't change.

LOOKAHEAD_MS default 160 re-run installer

Extra audio shown to the brain alongside each slice, from slightly in the future — like reading a sentence with the next word visible before deciding the previous one. It prevents words from being committed wrong just because their ending hadn't arrived yet.

When to change: rarely. It trades a little latency (the live text lags this many milliseconds behind your voice) for accuracy.

UNFIX_TOKEN_NUM default 1 re-run installer

How many of the newest words stay "in pencil" — revisable as more audio arrives. More pencil words = the model can fix recent mistakes better, but the live text wobbles more. Fewer = more stable live text, more chance an early mishearing sticks.

When to change: experimentation territory. If you enjoy watching the live text and hate seeing it rewrite itself, try 0.

§Voice detection (VAD)

These tune the pause detector described at USE_VAD. They only matter when USE_VAD=1. The detector listens in slices of one-hundredth of a second ("frames" — 10 milliseconds each), so a frame count is just a time in tenths-of-seconds: 8 frames = 80 ms, 20 frames = 200 ms. re-run installer applies to all four.

VAD_SPEECH_THRESHOLD default 0.4 re-run installer

How convinced the detector must be that a slice contains a voice, on a scale from 0 to 1. Lower = more eager to call something speech (catches whispers, but may trigger on keyboard clatter); higher = stricter.

When to change: if segments cut off when you speak softly, lower it toward 0.3; if it fires on background noise, raise toward 0.5.

VAD_MIN_SPEECH_FRAME default 8 (= 80 ms) re-run installer

The shortest noise that counts as "you started talking". Anything shorter is treated as a cough or a click and ignored.

When to change: raise it if lip-smacks and breaths keep starting fake segments.

VAD_MIN_SILENCE_FRAME default 20 (= 200 ms) re-run installer

How long you must stay silent before the detector decides the sentence is finished and banks the text so far. This is the "natural pause" length.

When to change: you habitually pause mid-sentence to think → raise it (30 = 300 ms). You want sentences banked aggressively → lower it.

VAD_MAX_SPEECH_FRAME default 2000 (= 20 s) re-run installer

The longest a single unbroken stretch of talking may run before the detector banks it anyway, even without a pause. A pressure valve so one rambling minute doesn't pile up uncommitted.

When to change: lower it if you want text banked more often during continuous speech.

§Where the AI lives

SERVER_DIR ~/apps/r2t2/Confucius4-R2T2 re-run installer

The folder on your computer where the AI brain (its program and the downloaded model, a few gigabytes) is installed.

When to modify: only if you deliberately move the installation — set the new path here before re-running ./install.sh.

PORT default 8272 re-run installer

The "door number" the brain listens on, on your computer. Two programs can't share a door.

When to modify: only if another program on this machine already uses door 8272 — then pick any free number between 1024 and 65535.

BIND_IP default 127.0.0.1 re-run installer

Who is allowed to knock on that door. 127.0.0.1 is computer-speak for "only this very computer" — nobody on your Wi-Fi can reach your microphone-driven AI, which is exactly what you want for something that transcribes speech.

When to change: only if you deliberately want to dictate from another device on your home network — and understand you'd be sending voice over the network to this machine. Keep the loopback address unless you have that specific reason.

GPU_INDEX default 0 re-run installer

Which graphics card to use, if you have several. 0 is the first one.

When to change: multi-GPU machines where card 0 is busy with something else (big AI workloads often grab card 0 first).

§Common recipes

The settings above, arranged by what you're actually trying to do.

You want…Do this
Better accuracy on names and jargon Set CONTEXT to the names you use. This is the #1 fix. Takes effect next dictation.
Dictate in another language / mix Chinese + English Change VOICE_LANG.
Stop accidental "send" in chat apps Already fixed in the current version (stray Enter and | artifacts are stripped before typing). If you still see it, update via ./install.sh.
Free up graphics memory for games Lower GPU_MEM_UTIL (e.g. 0.45), or MAX_MODEL_LEN=4096, or both. Re-run the installer.
Room for very long dictations Raise MAX_SECS (client-side) and, if memory allows, MAX_MODEL_LEN and MAX_NEW_TOKENS.
Less GPU usage while the machine is busy CHUNK_SIZE_MS=320 — the live text just updates in bigger steps.
Last word keeps getting cut off Raise GRACE_TAIL to 0.4.
Text arrives with weird extra behavior when it appears Raise SETTLE_DELAY to 0.3 (the modifier-key "glue" issue).
Wrong microphone is recorded Find its id with wpctl status and set MIC_TARGET.
See if you're being recorded from across the room Keep BORDER=1; recolor with BORDER_COLOR.
Golden rule: CONTEXT first. Every other knob on this page tunes mechanics; that one tunes understanding.
